Fateh Shopify Connector · v15.1.0

Every order, item, and stock level — in sync.

A multi-store Shopify integration for ERPNext. Any number of Shopify stores connect to one ERPNext instance, each mapped to its own company, with real-time webhooks and configurable automation.

Capabilities

What the connector does

Ten integrated features covering the full Shopify → ERPNext lifecycle, from order ingestion to inventory pushback.

Multi-Store, Multi-Company

Connect unlimited Shopify stores to one ERPNext instance. Each store maps to a separate company for clean accounting separation.

Real-Time Order Sync

Webhook-based ingestion with HMAC validation. Orders route to the correct company automatically. Supports auto-submit, invoicing, and payment entry creation.

Fulfillment → Delivery Notes

Shopify fulfillment webhooks create Delivery Notes with tracking numbers. Handles partial fulfillments and prevents duplicate DNs.

Product & Inventory Push

Sync ERPNext items to Shopify with configurable field mapping (standard fields and metafields). Push stock levels with multi-location support via GraphQL batching.

Configurable Tax Handling

On-Net-Total tax approach, zero-rated item detection, per-store tax account mapping, and automatic rounding adjustments so ERPNext totals match Shopify exactly.

Collection Mapping

Map ERPNext field values (item group, brand, etc.) to Shopify Custom Collections. Optionally auto-create collections for unmapped values.

Payment Method Mapping

Map Shopify payment gateways to ERPNext Mode of Payment. Payment entries fail fast if a gateway isn't mapped — no silent mismatches.

OAuth 2.0 Authorization

Full OAuth flow — authorize directly from the Shopify Store form. The access token is stored and managed automatically after authorization.

SKU-Based Migration Tool

Fetch existing Shopify products and map them to ERPNext items by SKU match. Reports matched, unmatched, and conflicting items before committing.

Item Eligibility Filters

Control which items sync to each store. Manual per-item overrides or automatic filter rules — e.g. "sync to this store if Item Group is Electronics."

Authentication

The connector uses OAuth 2.0 exclusively. Shopify deprecated legacy private apps in January 2026 — all new apps must use OAuth.

OAuth 2.0

Authorize directly from the Shopify Store form. The connector handles the full OAuth flow — the access token is stored automatically after authorization and refreshed as needed.

  • Create an app in the Shopify Dev Dashboard (dev.shopify.com)
  • Copy the Client ID and Client Secret into the Shopify Store form
  • Save the form — the Callback URL field is populated automatically
  • Add the Callback URL to Shopify's "Allowed redirection URL(s)"
  • Click Actions → Connect to Shopify
  • Authorize on Shopify — OAuth Status becomes Connected
Callback URL:
https://[your-site]/api/method/fateh_shopify_connector.fateh_shopify_connector.connection.store_request_data
Required OAuth Scopes
read_orders, write_orders read_customers, write_customers read_products, write_products read_inventory, write_inventory read_locations read_fulfillments, write_fulfillments
Setup Guide
Step 0

Prerequisites

Confirm all of these before starting. Each item is required — a missing one will cause the OAuth flow or webhook processing to fail.

✓
ERPNext v15 or later is running

Run bench version to confirm. The connector is incompatible with v14 and earlier.

✓
fateh_shopify_connector is installed and migrated

Run bench --site [site] list-apps to confirm, then bench --site [site] migrate to apply DocTypes and fixtures.

🔗
ERPNext site is publicly accessible over HTTPS

Shopify sends webhooks to your URL — it must be reachable from the internet. For local development, configure localtunnel_url in site_config.json.

🛍
Admin access to the Shopify store and Dev Dashboard

You need Shopify Admin → Settings → Apps access and access to dev.shopify.com to create the OAuth app.

🏢
ERPNext Company, Chart of Accounts, and Warehouses are set up

The connector maps each Shopify store to an ERPNext Company. That company must have a complete Chart of Accounts, at least one Warehouse, and a default Cost Center before order sync will work.

💡
Multi-store setup: Repeat Steps 1–8 for each Shopify store. Each gets its own Shopify Store document with independent company, warehouse, and tax settings. The Shopify Dev Dashboard app (Step 1) can be shared across stores.

Shopify Side

Create the Shopify App

The connector requires a Shopify app created in the Shopify Dev Dashboard (not the older "Develop apps" flow inside Shopify Admin). This gives you the Client ID and Client Secret for the OAuth flow.

⚠
Shopify deprecated legacy private apps from January 2026. All new integrations must use OAuth. The connector no longer accepts legacy access tokens.
Dev Dashboard Setup
1

Open the Shopify Dev Dashboard

Go to dev.shopify.com and sign in with your Shopify Partner or store account. A Partner account is free and required for the Dev Dashboard.

2

Navigate to Apps → Create app

Click Apps in the left sidebar, then Create app. Give it an internal name (e.g. "Fateh ERP Connector") — this appears in Shopify Admin under installed apps.

3

Create a version

Inside your new app, click Versions → Create version. You configure redirect URI and scopes on this version.

4

Get Client ID and Client Secret

Click Client credentials. Copy both values — you'll enter them into ERPNext in Step 2. Keep the Client Secret confidential.

In Allowed redirection URL(s), add your ERPNext callback URL (also shown on the Shopify Store document after Step 2):

ERPNext Side

Connect via OAuth

After saving the Shopify Store document, initiate the OAuth authorization flow to grant the connector permission to act on behalf of your store.

1

Open the saved Shopify Store document

The document must be saved (not new) with valid Client ID and Client Secret entered.

2

Click Actions → Connect to Shopify

This button appears in the Actions menu when Client ID is populated. Clicking it redirects your browser to Shopify's authorization page.

3

Authorize on Shopify

Review the permissions list and click Install app. You are redirected back to ERPNext automatically.

4

Verify: OAuth Status = Connected

Reload the Shopify Store document. oauth_status should show Connected and the dashboard banner confirms the authorized user.

5

Test the connection

Click Actions → Test Connection. If successful, a green message shows your Shopify shop name and email.

ℹ
Token rotation: OAuth tokens do not expire unless you revoke the app or change scopes. After adding new scopes, re-authorize by clicking "Connect to Shopify" again — the old token is replaced automatically.

ERPNext Side

Map Shopify Locations to Warehouses

Shopify locations correspond to ERPNext warehouses. Map at least one location before inventory sync or fulfillment processing will work correctly.

1

Click Actions → Fetch Shopify Locations

Calls the Shopify Locations API and populates the Warehouse Mapping table with your Shopify location IDs and names.

2

Assign an ERPNext Warehouse to each location

In the Warehouse Mapping table, set erpnext_warehouse for each Shopify location. The warehouse must belong to the same company configured in Step 2.

3

Set a Default Warehouse

In Inventory Settings, set the warehouse field. This is the fallback used when a Shopify location has no explicit mapping.

💡
Inventory sync direction is ERPNext → Shopify: stock levels in ERPNext are pushed to Shopify, not the other way. If you use a single Shopify location, one mapping row is sufficient.

ERPNext Side

Configure Tax Settings

Tax configuration determines how Shopify's tax lines map to ERPNext Sales Tax accounts. Incorrect mapping causes order totals to mismatch between Shopify and ERPNext.

FieldDescriptionRequired?
default_sales_tax_accountERPNext account used for GST/VAT when no specific tax title mapping exists. Must be a Tax-type account.Recommended
default_shipping_charges_accountIncome account for shipping charges when Add Shipping as Item is off.Recommended
write_off_accountAccount for rounding adjustments. Falls back to the company's Write Off Account if not set.Recommended
tax_accounts (table)Per-title overrides: map a Shopify tax title (e.g. "VAT 15%") to a specific ERPNext account and optionally a zero-rated Item Tax Template.Optional
ℹ
How tax calculation works: The connector uses the On Net Total approach. Each Shopify tax line becomes a row in the Sales Order Tax table. The rate is back-calculated from Shopify amounts — no tax templates are required unless you need zero-rating support.

Shopify Side

Register Webhooks

Webhooks are the real-time connection between Shopify events and ERPNext. Register them once — they persist in Shopify until you update or delete the app.

1

Configure which webhook events to enable

In the Webhook Events section of the Shopify Store document, toggle the events you need. All five are enabled by default.

2

Click Actions → Register Webhooks

A confirmation dialog appears. Clicking Continue clears any existing webhooks for your site from Shopify, then registers fresh ones for the enabled events.

3

Verify: Fetch and inspect webhooks

Click Actions → Fetch Webhooks. A dialog lists each webhook's topic and callback URL — confirm your site URL appears.

4

When to re-register

Re-register when you change the site domain, enable or disable webhook events, or Shopify reports delivery failures. Shopify auto-disables webhooks after repeated failures — watch Fateh Shopify Log for error patterns.

ℹ
HMAC validation: Every incoming webhook is verified against the Client Secret (or Shared Secret if set). If validation fails, the connector logs an error and drops the payload. The Shared Secret field lets you use a separate secret if needed.

Troubleshooting

Common Issues

Most issues leave a trace in Fateh Shopify Log. Check Status = Error entries there first — the Traceback field usually points directly at the problem.

OAuth authorization fails or redirects to an error page
The most common cause is a redirect URI mismatch. The Callback URL in ERPNext must exactly match what's in Shopify's "Allowed redirection URL(s)" — including https:// and no trailing slash. Also verify Client ID and Client Secret are correct (copy-paste, don't retype). Save the ERPNext document, then re-authorize.
Webhooks are not triggering (no log entries for orders)
First confirm the store is Enabled. Click Actions → Fetch Webhooks — if none are listed, click Register Webhooks. Also confirm your ERPNext site URL is publicly accessible. In development, set localtunnel_url in site_config.json before registering webhooks.
Webhook log shows "Unverified Webhook Data (signature mismatch)"
The HMAC validation failed — the Client Secret in ERPNext doesn't match what Shopify used to sign the webhook. Re-check your Client Secret (copy from Shopify Dev Dashboard). If you've set a Shared Secret, it takes precedence — clear it or ensure it matches. After fixing the secret you don't need to re-register webhooks.
Sales Order created but total doesn't match Shopify
Almost always a tax mapping issue. Check the log's response data for Shopify tax lines. Ensure a default_sales_tax_account is set. For specific Shopify tax titles (e.g. "Customs") without a mapping, add them to the Tax Accounts table. Also confirm Write Off Account is set — without it, rounding differences become unreconciled discrepancies.
Items in Shopify orders are not found in ERPNext
The connector matches by SKU (Shopify variant SKU → ERPNext Item Code). Use Actions → Fetch Products & Map by SKU to run the mapping job. Items without an ERPNext match must be created manually first.
Payment Entry fails with gateway not mapped error
Each Shopify payment gateway must have a row in the Payment Method Mapping table. The gateway name must match exactly — find the exact name in Fateh Shopify Log's request data (payment_gateway_names field). Common names: Shopify Payments, Manual, Cash on Delivery (COD).
Inventory sync isn't pushing stock to Shopify
Check: (1) Enable Inventory Sync is on. (2) The item has an Item Shopify Store row with shopify_inventory_item_id populated. (3) The warehouse matches a mapped warehouse. (4) Background workers are running — check bench doctor. The scheduler runs every 10 minutes.
